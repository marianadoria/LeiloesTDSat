# Leilões TDSat

## Sobre o Projeto
O **Leilões TDSat** é um sistema informatizado desenvolvido para gerenciar as rotinas de uma casa de leilões, permitindo o cadastro, a listagem e o controle de status de venda dos produtos disponibilizados para leilão.

## Tecnologias Utilizadas
- **Java** (Java SE / Swing para interface gráfica e JDBC para conexão de dados)
- **MySQL** (Sistema de Gerenciamento de Banco de Dados)
- **Git & GitHub** (Controle de versão)
